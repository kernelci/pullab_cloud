# AWS Config Specification

All fields for `config.json`. Generated by `kernel-ci-cloud-runner aws setup configure`.

## Root

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `provider` | string | yes | `"aws"` |
| `region` | string | yes | AWS region (e.g. `"us-west-2"`) |
| `force_recreate_roles` | bool | no | Delete and recreate IAM roles. Default `false`. ⚠️ Terminates running tasks. |

## `auth_credentials`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `auth_provider` | string | yes | `"aws"` |

## `storage`

Results bucket for test output, logs, and benchmark CSVs.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | string | yes | `"s3"` |
| `bucket` | string | yes | S3 bucket name. Account ID appended if name is taken. |
| `results_prefix` | string | no | Prefix path within bucket. Default `"results"`. |

## `external_storage`

Separate bucket for kernel RPMs and test scripts (shared across runs).

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | string | yes | `"s3"` |
| `bucket` | string | yes | S3 bucket name for RPMs and test scripts. |

## `test_config`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `test_id` | string | yes | Identifier for the run. Expanded with datetime stamp. |
| `role_name` | string | yes | IAM role name for EC2 instances. Must match a key in `roles`. |
| `vms` | array | yes | List of VM configurations (see below). |

### `test_config.vms[]`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `ami_id` | string | yes | AMI ID or `"resolve:ssm:/aws/service/..."` for SSM lookup. |
| `instance_type` | string | yes | EC2 instance type (e.g. `"c5a.4xlarge"`). |
| `max_runtime` | int | yes | Max seconds per VM. Watchdog shuts down VM after this. SSM timeout is `max_runtime + 3600`. |
| `test` | array | yes | Test directory names from `vm-tests/`. |
| `min_count` | int | yes | Number of VMs to spawn with this config. |
| `test_params` | object | no | Extra parameters passed to test scripts. |

## `roles`

Keyed by role name. Each role defines trust policy, managed policies, and inline policies.

### `roles.<name>`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `description` | string | no | Role description. |
| `trust_policy` | object | yes | IAM trust policy document (who can assume the role). |
| `policies` | array | yes | List of managed policy ARN strings. |
| `inline_policies` | object | yes | Dict of `{policy_name: IAM policy document}`. |

Example:
```json
{
  "description": "ECS task execution role",
  "trust_policy": { "Version": "2012-10-17", "Statement": [...] },
  "policies": [
    "arn:aws:iam::aws:policy/service-role/AmazonECSTaskExecutionRolePolicy"
  ],
  "inline_policies": {
    "AllowEC2": { "Version": "2012-10-17", "Statement": [...] }
  }
}
```
